# 📚 Books Slim

Минималистичное веб-приложение для управления библиотечным каталогом, построенное на микрофреймворке **Slim**. Проект демонстрирует полный цикл CRUD-операций с записями книг, систему аутентификации и разделение прав для обычного пользователя и администратора.

## 🚀 Основной функционал

*   **Главная страница:** Отображает все записи из базы данных с объединением информации из двух таблиц.
*   **Аутентификация:** Реализована регистрация и вход в систему. Пароли надёжно хешируются.
*   **Роли пользователей:** Обычные пользователи имеют базовый доступ, а администратор после входа перенаправляется в панель управления.
*   **CRUD для книг:** Администратор может:
    *   Добавлять новые книги.
    *   Просматривать детальную информацию.
    *   Редактировать существующие записи.
    *   Удалять книги из каталога.
*   **Отслеживание статуса:** Для каждой книги отображается её статус (находится в библиотеке или выдана).

## 🛠 Технологии

*   **Backend:** PHP 8+, Slim Framework 4
*   **Шаблонизация:** Twig
*   **База данных:** MySQL
*   **Окружение:** Docker / Docker Compose
